# Design

PasteGuard is an investigation worksheet inspired by printed evidence folders. Warm paper, crisp black rules and signal yellow identify actions. Rust highlights a source line that needs attention. Keep the page in reading order from source to findings to transfer evidence. The workbench uses a dark code surface beside an ordered finding list, and the transfer comparison pairs two destinations with equal visual weight. Keyboard focus, readable evidence labels, and a stacked mobile layout support both reading and operating.
