# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated. A static Vite app uses JavaScript, Acorn, and Solana Kit.

## Users

People evaluating a pasted userscript before installation, and hackathon judges reviewing a demonstration of deposit-address substitution.

## Product purpose

Show source-level evidence of browser privileges, remote code loading, and payment manipulation. Connect a known destination substitution to a real Solana transfer preview.

## Capabilities and constraints

Analyze JavaScript as local text. Leave external payloads unresolved. Accept an independently supplied recipient for comparison. Run only app-built transfer simulations against Solana devnet. Use a sanitized reconstruction for the demo.
